# asd-ste100-zh

先完成清楚的英文报告，再输出自然、准确的中文。适用于进展、交付、排障、调研和决策汇报，默认中文，也支持英文或双语对照。

## 安装

```bash
npx skills add Kuro96/asd-ste100-zh --skill asd-ste100-zh
```

或克隆到宿主的 skill 目录：

```bash
git clone https://github.com/Kuro96/asd-ste100-zh.git ~/.claude/skills/asd-ste100-zh
```

## 使用

```text
用 asd-ste100-zh 整理这些排障记录，给出结论、证据和剩余事项，输出中文。
```

工作流：**事实与术语 → 英文成稿 → 语境化中文 → 双语核对**。

详见 [技能说明](<SKILL.md>)和[双语示例](<examples/bilingual-reports.md>)。
